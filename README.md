## Abstract

PackRight is a warehouse order packing system that focuses on making the
process of packing and shipping orders easier and more efficient. In
warehouses, many items need to be packed into boxes and loaded into
trucks based on their weight, available capacity, and delivery
schedules. Managing all these things manually can take more time and
effort.

This project uses different Data Structures and Algorithms concepts to
solve common warehouse problems. It helps find pairs of items that fit a
box, select the best combination of items within a given weight limit,
calculate the number of units packed during a particular time, and find
the suitable truck capacity for delivering orders. It also helps manage
dock bookings by identifying and combining overlapping time slots.

The project uses concepts such as hashing, memoisation, dynamic
programming, prefix sums, sliding windows, binary search, and sorting.
By implementing these concepts, we aim to reduce unnecessary work and
improve the overall efficiency of warehouse operations.

The main objective of PackRight is to understand how the DSA concepts
learned in class can be applied to real-world problems. Through this
project, we gain practical experience in coding, logical thinking, and
finding efficient solutions to everyday warehouse management challenges.
